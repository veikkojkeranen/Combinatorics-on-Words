Image words in colour g85(a), g98(a) and g109(a), and their squares g85²(a), g98²(a) and g109²(a), letter by letter

V. KeränenWorking notes, 8 November 2026Drawn with Claude Code

The letters are coloured a red, b green, c yellow and d blue. In the squares, each row is one block, the image of one letter of g(a), and every letter has a square cell. So g²(a) is drawn as an |g(a)| × |g(a)| square, with the blocks lined up under each other. The colour pattern of each block is a recolouring of the first one.

All six words are abelian square-free. The page checks this when it loads; the result is shown under each word.

2 · The squares g²(x), one block per row

Choose the letter x ∈ {a, b, c, d} with the buttons a b c d next to each heading; the square then shows g²(x), with the blocks g(y) for the letters y of g(x). Each g²(x) is a recolouring of g²(a), so all of them are abelian square-free too; the page checks each one when you choose it. Hover over a letter to see its position. In g109²(x) every block has its moving letters at offsets 17 and 48, so they form two marked columns.

The diagonals. The diagonal of the square g²(a) consists of the letters g(xr)[r] for r = 1, …, |g(a)|, where xr is the rth letter of g(a). The letter g(xr)[r] is at position (r − 1)(|g(a)| + 1) + 1 of g²(a), so the diagonal positions 1, |g(a)| + 2, 2|g(a)| + 3, … form an arithmetic progression with difference |g(a)| + 1. In g98²(a) all 98 diagonal letters are a. The reason is how the four images of g98 are related. With σ the cyclic recolouring a → b → c → d → a, the images satisfy g98(σk(a)) = σ−k(g98(a)): the recolouring runs backwards. If xr = σk(a), the diagonal letter is σ−k(xr) = σ−k(σk(a)) = a. For the cyclic morphisms g85 and g109, g(σk(a)) = σk(g(a)), so the diagonal letter is σ2k(a), which is a or c: the diagonal of g85²(a) has 46 a's and 39 c's, that of g109²(a) 50 a's and 59 c's. For other x the same argument with x = σj(a) gives: in g98²(x) every diagonal letter is x, and in g85²(x) and g109²(x) the diagonal letters are σj+2k(a), so a and c for x ∈ {a, c} and b and d for x ∈ {b, d}. Tick “frame the diagonal” to see it.

3 · The image words as coloured disks, in your own lines

Each letter is a coloured disk. There are two ways to break g(a) into lines. Cut every n letters gives lines of equal length. Own layout reads the text box: a “.” ends the line after it, a space leaves an empty place as wide as one disk, and a line break also ends a line. Any other characters are ignored. The page checks that the letters of the layout, read in order, spell g(a) exactly. “Take the cut layout” copies the current cut into the text box as a starting point.
